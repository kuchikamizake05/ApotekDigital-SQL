# Apotek Digital SQL

Repositori ini berisi skrip SQL untuk manajemen database Apotek Digital.

## Cakupan Proyek
- **DDL**: Pendefinisian struktur tabel (Pelanggan, Obat, Transaksi, dll).
- **DML**: Manipulasi data (Insert, Update, Delete).
- **DQL**: Query pengambilan data mulai dari yang sederhana hingga kompleks (Join & Subquery).

## Cara Penggunaan
1. Import file potek_digital.sql ke dalam MySQL/MariaDB.
2. Jalankan skrip untuk menginisialisasi database dan data sampel.
